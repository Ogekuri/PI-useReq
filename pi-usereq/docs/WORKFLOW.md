## Communication Edges
- Internal process communication edges: none. `PROC:main` and `PROC:pi-host` are distinct runtime entry modes; `PROC:pi-host` executes inside the external pi CLI host process and never exchanges data with `PROC:main`.
- Internal thread communication edges: none.
- Relationship note: both execution units share the same internal `src/` module families (`src/core/tool-runner.ts`, `src/core/config.ts`, `src/core/static-check.ts`, and their dependencies) but instantiate them in separate processes.
