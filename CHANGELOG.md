## [0.109.0](https://github.com/Ogekuri/PI-useReq/compare/v0.108.0..v0.109.0) - 2026-11-12
### 🐛  Bug Fixes
- publish prebuilt tarball via explicit local path [useReq] *(release-npm)*
  npm parses a bare 'dist/pi-usereq-<version>.tgz' argument as a hosted-git
  GitHub shorthand, so publication ran 'git ls-remote
  ssh://git@github.com/dist/pi-usereq-<version>.tgz.git' and failed with
  exit code 128.
  emit artifact_path with an explicit './' local-file prefix that npm
  resolves as a file tarball instead of a hosted git repository
  document the shorthand hazard at the artifact-resolution and publish steps; add a regression test pinning the local-file publication path
- repair launcher and version reporting after source switch [useReq] *(package-manager)*
  re-point the agent-bin pi-usereq launcher onto the freshly installed
  channel target root after a successful pi remove/pi install source
  switch, so the management CLI cannot remain a dangling symlink
  resolve the post-switch completion version from the target installation
  manifest instead of the deleted runtime installation that owned the
  running process, removing the false unchanged-version warning
  add a reproducer covering launcher repair and target-root version
  reporting, and update WORKFLOW.md plus regenerated REFERENCES.md
- make postinstall bootstrap dependency-free for git installs [useReq] *(package)*
  Add scripts/install-static-checkers.js plain-Node wrapper that defers bundled
  checker installation when node_modules/tsx is absent, so npm git-dependency
  preparation clones never abort with ERR_MODULE_NOT_FOUND: Cannot find package
  'tsx'. The wrapper delegates to scripts/install-static-checkers.ts whenever the
  dependency tree exists, preserving the best-effort exit-code-0 installer and
  allow-scripts approval behavior (DES-017, REQ-339).
  Point the postinstall script at the wrapper, ship it in the npm files allowlist,
  and align the allowScripts version pins with the resolved dependency versions
  (esbuild 0.27.2, protobufjs 7.6.6, @google/genai 2.21.0).
  Add a reproducer suite covering the dependency-free clone path and update the
  files allowlist assertion (PRJ-009, REQ-482, REQ-484, CTN-020).
